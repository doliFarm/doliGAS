# doliGAS

An integrated management ERP for Solidarity Purchasing Groups (GAS), bridging community-driven logistics with Dolibarr’s robust backend to streamline sustainable food supply chains.

## Project Structure
- `/backend`: Node.js API with Express.
- `/frontend`: React application powered by Vite and Tailwind CSS.
- `/mysql-init`: Database initialization scripts for production and demo environments.

## Deployment
Managed via Docker Compose.
